# Delivery Quality Checklist

## Design review
- [ ] Spelling, punctuation, names, dates, prices, and links checked
- [ ] Brand colors, logo, and typography consistent
- [ ] Contrast and text size readable on a phone
- [ ] Safe margins respected; no cropped text or logos
- [ ] Visual hierarchy and CTA clear

## Motion review
- [ ] Correct dimensions, frame rate, duration, and format
- [ ] No black frames, missing media, broken fonts, or rendering glitches
- [ ] Audio levels checked and licensed / client-approved audio used
- [ ] Captions and on-screen text synchronized and readable

## Handoff
- [ ] Required export files included and named clearly
- [ ] Source project opens correctly; dependencies included where licensed and needed
- [ ] Delivery matches the agreed scope
- [ ] Revision count and remaining support explained clearly
- [ ] Backup stored securely; no credentials or unrelated client files included
